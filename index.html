Private backup utility

Personal GL Backups

An owner-operated utility for creating and verifying encrypted backups in the owner's Google Drive.

Purpose

The utility runs on the owner's private computers. It creates consistent database snapshots, encrypts them before upload, and downloads a copy to verify that the backup can be recovered.

Google Drive access

Google authorization lets the utility store and retrieve backups in a designated folder. The requested Drive permission is broader than that folder; the configured folder is an operational setting, not a Google-enforced permission boundary.

Not a public application

This website only provides information. It does not host the utility, display backup contents, accept uploads, or offer sign-in. No application source code, databases, backup files, or credentials are published here.
